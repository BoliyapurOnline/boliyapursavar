# Boliyapur Community Website

A free, responsive static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and Bangla content
- `style.css` — responsive modern design
- `script.js` — mobile menu, current year and contact-form email draft

## Before publishing
1. Open `index.html` and replace demo/sample copy with verified local information.
2. In `script.js`, replace `YOUR-EMAIL@example.com` with the community's real email address.
3. Add real local photos and verified contact details. The current illustrations/cards are design placeholders.
4. Test the contact form. It opens the visitor's email app; it does not store messages online.

## Publish free with GitHub Pages
1. Create/sign in to a free account at https://github.com
2. Create a new public repository named `boliyapur`.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then Save.
7. Wait for GitHub Pages to publish. Your site URL will be similar to `https://YOUR-USERNAME.github.io/boliyapur/`.

## Alternative: Netlify Drop
Visit https://app.netlify.com/drop and drag the extracted website folder onto the page. Netlify provides a free public URL (free-plan limits apply).

No paid domain or hosting is required. A custom domain is optional and usually costs money.
